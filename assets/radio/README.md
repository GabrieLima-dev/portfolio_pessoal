Coloque os arquivos de audio da radio nesta pasta.

Formatos suportados pelo componente:
- `.mp3`
- `.wav`
- `.ogg`
- `.m4a`

Regras:
- os arquivos sao carregados automaticamente pela radio
- o nome exibido vem do nome do arquivo
- depois de adicionar ou remover faixas, reinicie o `npm run dev`

Exemplos:
- `night-drive.mp3`
- `district_loop.mp3`
- `cold-terminal.mp3`
